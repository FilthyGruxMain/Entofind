<h1> Entofind Bot </h1>
<p> Entofind Bot is a Discord bot that pulls information from Entofind and replies to messages with that information. </p>

<h2> Installation </h2>
<p> Install Entofind Bot through: https://discord.com/oauth2/authorize?client_id=1551793367929851934&permissions=378880&integration_type=0&scope=bot </p>

<h3> Permissions </h3>
<p> The Oath2 authorizes Entofind to read messages, send messages, attach files, embed links, and use external emojis in your Discord server. If you have any server-specific settings that prevent this, the bot will not function properly </p>

<h2> Basic Usage </h2>
<p> Currently the only supported way to call Entofind Bot is to surround your card name in 2 square brackets. (i.e. "[[John Stick]]") </p> <img width="721" height="330" alt="image" src="https://github.com/user-attachments/assets/8838b87c-d1e1-475d-b099-3244ee1ba193" />

<p> Entofind Bot will return results if your name only corresponds to one card, so "[[Antonio]]" would prompt you to be more specific. </p>

<h3> Other Features </h3>
<p> Entofind Bot will first attempt to find cards that have an exact match with the name before checking to see if there are cards with a similar name. This enables you to find "[[Mars]]" despite there being multiple cards with the name. </p>
<p> You may also prompt Entofind to pull multiple cards in one message. </p> <img width="748" height="469" alt="image" src="https://github.com/user-attachments/assets/e26742c6-3c87-42d3-a119-28ec2046937a" />


<h2> Card Symbols </h2>
<p> Entofind Bot is enabled with external emojis of the card symbols for use in embedding within its messages. Download them under card_symbols. </p>
